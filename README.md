# Forest Fire Prediction

## Overview

A machine learning project to predict forest fire-related outcomes using environmental and weather conditions.

## Dataset

The dataset contains features such as:

* Temperature
* Relative Humidity
* Wind
* Rain
* FFMC
* DMC
* ISI
* classes

## Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## Workflow

```text
Dataset → Preprocessing → Train-Test Split → Model Training → Evaluation → Prediction
```

## Model Evaluation

The model is evaluated using appropriate metrics such as:

* MAE
* MSE
* RMSE
* R² Score

## Project Structure

```text
Forest-Fires/
├── notebooks/
├── models/
├── static/
├── templates/
├── app.py

```

## Run

